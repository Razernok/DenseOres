Dense Ores adds naturally generating dense variants of every vanilla ore in Hytale. These special blocks replace normal ore spawns at a configurable rate and drop 3x raw ore when mined, making resource gathering more rewarding without changing core gameplay mechanics.

Dense ores use the same textures and tool requirements as their standard counterparts but feature a custom model that visually makes them appear more compact and resource-rich.

🔹 Features

Dense variants for every vanilla ore
Dense ores generate naturally in the world
Replace normal ore spawns at ~30% by default
Each dense ore drops 3 raw ore
Same mining tier and break speed as normal ores

⚙ Configuration

Spawn rates are fully configurable per ore type, allowing server owners to fine-tune balance to their liking.

🔧 Compatibility

Compatible with other ore-adding mods. Automatically applies to modded ores. No dependencies required
